Duo Fold & View Swapping

Lightning-Fast View Swapping

Swap between Genie Block Home, Duo Fold Studio, Applications Atelier, and Imaginary Desktop in microseconds with zero redraw stutter or memory re-allocation.

  • ✓ Dynamic SF Symbol talisman button feedback
  • ✓ Smart View Routing: fills empty companion panes
  • ✓ Zero layout jank across ProMotion 120Hz displays
Vision & Ingestion

Natural Visual Reading Order OCR

State-of-the-art Apple Vision engine sorts recognized text lines by vertical midpoint descending and horizontal coordinate ascending, solving inverted Y-axis OCR drift on macOS.

  • ✓ Parses screenshots with timestamps and narrow spaces
  • ✓ CoreGraphics rasterization for scanned/image PDFs
  • ✓ Direct filesystem resolution from prompt path tokens
OLED Pillows

World Clock Pillows & Time Travel

Blackout specular rim cards with sweeping second hands, analog sweeps, and time-travel scrubbers to inspect daylight overlap ribbons across global timezones.

  • ✓ Tokyo, Seoul, London, New York, San Francisco
  • ✓ Once-per-minute deduplicated alarms
  • ✓ Looping audio & native UserNotifications
Companions

Living Dock Pets & Metal Shaders

6 interactive pets that reside on your Mac Dock and react dynamically to app state, typing cadence, and cursor motion. Enhanced with 12+ hardware-accelerated Metal shaders.

  • ✓ 🦊 Fox, 🐉 Dragon, 🐱 Kitten, 🦉 Owl, 🤖 Bot, 🐧 Penguin
  • ✓ Liquid Glass, Supernova Burst, Matrix Rain cursors
  • ✓ Sub-microsecond RAM-to-Metal framebuffers
Memory Architecture

Attention Sink Ring Buffer

Keeps the first N anchor context tokens and evicts the oldest sliding-window items into structured digests, permanently capping resident memory usage under 35MB.

  • ✓ 0% idle CPU and zero background battery drain
  • ✓ Infinite chat history without context explosion
  • ✓ Ideal for local Ollama & Apple MPS neural inferencing

  • ✓ Closed-source commercial binary with full user sovereignty
