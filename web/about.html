Core Engine

The master spatial operating framework managing Darwin WindowServer C primitives, 120 FPS Metal 3 pipelines, 81-screen continuous spaces, and spatial windowing transforms.

Autonomous AI

⚙️ GenieAgentCore

Autonomous agent runtime and execution barrier engine. Features pre-execution atomic JSON checkpointing, atomic byte-level read-back diffs, and validated native tool catalog routing.

⚡️ GenieEnvironmentKit

Direct host and guest micro-virtualization manager utilizing Apple's Virtualization.framework (VZVirtualMachine) and memory-mapped Virtio-FS for sub-50ms ephemeral Linux runtimes.

Native macOS Finder Sync extension target delivering contextual item menus, real-time filesystem tracking, dynamic badge overlays, and seamless desktop triage.

FinderSync.framework Contextual Menus File Tracking
