# User Guide — Genie for macOS

Welcome to Genie. This guide covers everything you need to know to get the most out of the app.

---

## Getting Started

### First Launch

On first launch, the **Quick Setup Wizard** walks you through:

1. Granting Accessibility permissions (optional — required only for global keyboard shortcuts)
2. Choosing your preferred **default formation** (Responsive Grid is recommended)
3. Enabling **Launch at Login** so Genie is always available
4. Taking a quick tour of the Studio tabs

You can re-launch the wizard at any time from **General → Quick Setup Wizard**.

### The Menu Bar Glyph

Genie lives in your macOS menu bar as an animated status glyph. Click it to open and close the **Studio** panel.

## The Desktop Canvas

### Summoning & Dismissing

| Method | Action |
|---|---|
| Click menu bar glyph | Toggle Studio panel |
| Two-finger scroll up | Summon app matrix |
| Two-finger scroll down | Dismiss to clean desktop |
| Three-finger swipe | Express navigation |
| Hover cursor at bottom-centre screen edge | Summon (after configurable delay) |
| Click empty wallpaper area | Dismiss |
| Double-click empty wallpaper | Toggle grid |
| Middle or back mouse button | Toggle grid |
| `⌃⌃` double-tap Control key | Quick Summon / Dismiss from anywhere |

### Page 1 — App Matrix

Your full application catalogue, rendered as a fluid geometric formation over your desktop.

- **Launch an app** — Single click.
- **Right-click an app** — Context menu: Open, Reveal in Finder, Hide from Genie, Move to Top.
- **Reorder apps** — Long-press or right-click → Edit Mode. Drag icons to new positions. Tap `Escape` or click outside to exit Edit Mode.
- **Search** — Open the Studio Apps tab and type. The canvas filters live.

### Page 0 — Clean Desktop

A pristine view of your desktop wallpaper with full native Finder access. Desktop files, lasso selection, and drag-and-drop all work exactly as expected.

## Studio Control Hub

Open the Studio by clicking the menu bar glyph. The panel is **freely movable** and **resizable** — drag the title area to reposition, drag any edge to resize.

### Apps Tab

- **Search bar** — Type to filter your app catalogue in real time.
- **Category chips** — Filter by App Store category (Productivity, Creative, Developer, etc.)
- **Running apps section** — Apps currently open are highlighted.
- **Eye icon** — Toggle visibility of individual apps in the canvas.
- **Refresh** — Re-scan your Applications folder.

## Troubleshooting

**The app matrix doesn't appear when I scroll up.**  
Ensure Genie has Accessibility permission: System Settings → Privacy & Security → Accessibility → enable Genie.

**My custom app order reset.**  
Long-press on an icon to enter Edit Mode, rearrange, then press `Escape` to save.

**The Studio panel disappeared off-screen.**  
Go to General tab → Reset Panel Position. Or delete `nexus.popoverCustomX` and `nexus.popoverCustomY` from `UserDefaults`.

**The menu bar glyph animation is slow.**  
Increase animation speed in the Status Bar tab, or reduce the number of active visual effects in Motion & FX.

**An app I installed doesn't appear.**  
Tap the Refresh button in the Apps tab, or quit and relaunch Genie.

**My VIP Pack purchases aren't showing after reinstall.**  
Open the VIP Packs tab and tap **Restore Purchases**.
