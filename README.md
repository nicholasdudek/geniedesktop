# Genie — Desktop Workspace

> Next-generation macOS spatial workspace and application launcher engineered natively with Swift and Metal.

Official website source for [Genie on the Mac App Store](https://apps.apple.com/app/id6808165534).

## Features
- **Spatial Desktop Canvas**: Launch and organize applications in dynamic geometric formations.
- **Metal Shaders**: Translucent frosted aero glass, living wallpapers, and custom GPU materials.
- **Zero Telemetry**: 100% offline, privacy-first architecture with no network entitlements.
- **StoreKit 2**: Frictionless expansion packs through Apple's native in-app purchasing.
