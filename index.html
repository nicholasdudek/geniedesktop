Spatial Windowing Engine

Direct macOS WindowServer level injection. Toggles seamlessly between clean desktop wallpaper layer (.desktopIconWindow - 1) and an elevated 120 FPS interactive spatial canvas without stealing menu bar focus.

NSWindow.Level DesktopWindowManager.swift Always-On Matrix
🎯

Smart Retractor & Inset Avoidance

Invisible top-edge cursor hover detector (location.y <= 6) glides the canvas smoothly away without intrusive buttons. Includes an intelligent Dock inset protection engine with a 0.45s rest period.

onContinuousHover DockAndDesktopManager Zero Visual Clutter
