New in Build 500

Autonomous OS Agent, In-RAM Hypervisor & Duo Fold Studio

Genie's massive Build 500 is here. Genie is now an autonomous OS Agent operating directly inside macOS and Linux. Using native CoreGraphics (CGEvent) input injection, Genie snaps the cursor, executes clicks, double-clicks, drags, and enters keystrokes with zero-latency visual coordinate grounding. All 12 legacy control center tabs (Apps, Desktop, Themes, VIP Packs, etc.) have been fully restored and integrated natively into the iPad Duo Fold code editor as swipeable tabs. Under the hood, GenieHypervisorEngine boots instant macOS and Linux virtual machines directly inside RAM. By predictively memoizing visual states, UI rendering overhead drops to near zero—freeing 99.9% of CPU capacity for Headless Background Swarms that speculatively pre-compute code, run tests, and index data before you even click.
